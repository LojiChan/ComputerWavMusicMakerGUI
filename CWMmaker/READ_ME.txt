一、控制标记（用 {} 包裹）
标记	含义	示例
{bpm:数字}	设定速度（拍/分钟）	{bpm:80}、{bpm:148}
{f:字母}	调性标记	{f:G}、{f:C}
{1=字母}	首调唱名对应	{1=G}、{1=C}
{t:...}	特殊处理标记	{t:6-、{t:6g=6xgx6g-
{{...}}	重复段	{{6dx6dx...|...}}
注意：解析器目前忽略 {f:X} 和 {1=X}，整曲按 1=C 处理。如果你要转调准确，得在解析器里加上调性偏移。

二、音符（数字 1–7）
基本音就是简谱的七个音级：

数字	唱名
1	do
2	re
3	mi
4	fa
5	sol
6	la
7	si
三、音高修饰（数字后紧跟）
修饰符	含义	示例
d	低八度（"低"）	6d = 低八度的 la
g	高八度（"高"）	1g = 高八度的 do
#	升半音	5d# = 低八度的升 sol
b	降半音	7b = 降 si
可叠加：6d、1g、5d#、3g 都合法。

四、时值（数字后）
符号	含义	相对四分音符
无	四分音符	1 拍
x	十六分音符	0.25 拍
-	延长一拍	+1 拍
.	附点（×1.5）	×1.5
=	延音线（与后一同音合并）	合并时值
组合示例：

写法	含义	总时值
6d	低八度 la，四分音符	1 拍
6dx	低八度 la，十六分音符	0.25 拍
6d-	低八度 la，延长一拍	2 拍
6d--	低八度 la，延长两拍	3 拍
6d---	低八度 la，延长三拍	4 拍
6d.	低八度 la，附点四分	1.5 拍
6d=x	低八度 la，与下一同音合并十六分	1.25 拍
6dx3	三个连续十六分 6d	0.75 拍
五、休止符（0）
写法	含义
0	四分休止
0x	十六分休止
0-	延长一拍休止
0---	三拍休止（整个小节）
六、小节线
符号	含义
|	小节线
||	终止线
七、括号与连接
符号	含义	处理
( )	连音或特殊分组	解析器跳过，不改变时值
t:	特殊连音标记	解析器跳过
{{ }}	重复段	解析器忽略标记，但其中音符正常解析
八、完整示例解析
以你乐谱开头的两小节为例：

text
{bpm:80}6dx3=2=3x5x6-|6dx3=2=3x5x6-|
逐步拆解：

记号	解释	音高	时值
{bpm:80}	设定速度为 80	—	—
6d	低八度 la	220.00 Hz	0.25 拍
x3	再重复两次十六分	220.00 Hz ×2	0.25 ×2
=2=	延音线后接 re	293.66 Hz	0.5 拍
3x	十六分 mi	329.63 Hz	0.25 拍
5x	十六分 sol	392.00 Hz	0.25 拍
6-	la 延长一拍	440.00 Hz	2 拍
|	小节线	—	—
第一小节总时值：0.25×3 + 0.5 + 0.25 + 0.25 + 2 = 4 拍（符合 4/4 拍）。

九、解析器支持度对照表
记号	是否支持	说明
1–7	✅	基本音
d g	✅	八度移位
# b	✅	升降半音
x	✅	十六分音符
-	✅	延长
.	✅	附点
=	✅	同音延音合并
0	✅	休止
|	✅	小节线（跳过）
{bpm:N}	✅	速度变化
{f:X} {1=X}	❌	忽略，按 1=C 处理
( )	❌	忽略，不改变时值
{t:...}	❌	忽略
{{...}}	❌	标记忽略，音符正常
十、如果想扩展乐谱格式
你可以在 SheetMusic.txt 里用同样的语法写任何简谱。只要遵循上面的规则，解析器就能读。比如加一段自己的旋律：

text
{bpm:120}1 2 3 5|6 5 3 2|1---||
（注：实际写的时候不要有空格，空格会被当作跳过字符。）

总结一句话：这套格式 = 标准简谱 + d/g 八度 + x 十六分 + - 延长 + = 延音 + {} 控制标记。

CWMmaker & 童祭交响编曲
这是什么
一个把简谱变成 WAV 的小工具，以及用它做出来的一份《童祭 ～ Innocent Treasures》交响改编。

CWMmaker 是我为了给《东方 Project》的曲子做无版权负担的合成演奏而写的一个 Python 程序。它把标准的简谱文本（.txt）直接解析成音频，不需要 MIDI 音源、不需要采样库、不需要 DAW。所有声音都是程序现场合成的。

SheetMusic.txt 里放的是一首《童祭》的完整简谱，五条轨道分别用不同的合成音色演奏，组合成一段约两分钟的交响版本。

它为什么存在
市面上做"简谱转音频"的工具不少，但大多数要么依赖庞大的音源库，要么把谱子转成 MIDI 再由外部软件渲染。这个项目想试一件事：只靠 Python 和 numpy，从零合成一整套乐器音色，并且这个音色在听感上能让普通人认出"这是钢琴""这是小提琴""这是人声"。

结果不好不坏。钢琴、竖琴、吉他这类拨弦乐器效果尚可；管乐和人声距离真实乐器还有距离，但作为"能听出轮廓"的合成版本，够用了。

合成器的做法
音色不是采样、不是波表素材，而是加法合成 + 波表缓存：

每种乐器定义一组谐波幅度和衰减率（参考了乐器声学的公开资料：钢琴的非谐性、小提琴的琴体共振、单簧管的奇次谐波主导、长笛的纯净频谱等）

按每 3 个半音一个精度，把谐波序列预生成成波表

音符按相位累加器查表播放，速度接近实时

在 2 倍采样率下做非线性运算（软削波、噪声、包络），最后用抗混叠滤波器降到 44.1 kHz

这样做的好处是不会有采样库的"机械感"和"音域断层"，坏处是音色精度受限于谐波数量。目前的实现里最复杂的音色用了 24 个谐波，简单音色 5 到 12 个。

《童祭》交响版
《童祭 ～ Innocent Treasures》是 ZUN 为《东方 Project》音乐专辑《夢違科学世紀》写的曲目，是东方圈里非常经典的一首。原曲结构并不复杂：一个 4/4 拍的主歌主题，反复出现并在不同段落里变换速度和配器。

这份改编把原曲整理成一段约两分钟的室内乐合奏：

乐器	角色
少女唱诗班	主旋律
小提琴	对位副旋律
竖琴	琶音背景
钢琴	低音根音
长笛	高音点缀
编制里"少女唱诗班"不是真实人声采样，而是用脉冲串激励 + 共振峰滤波合成的模拟人声。听感上介于人声和电子音之间，可以理解为"合唱音色的近似"。

原曲有好几个 BPM 变化（80 → 90 → 148 → 120 → ... → 46）。在这份改编里，我统一取 76 BPM，因为合奏版本如果跟着原曲的速度变化，不同声部会越走越错位。统一速度后五条轨道才能严格同步。

谱子是用 CWMmaker 的文本格式写的，跟着 SheetMusic.txt 走。每条轨道的音量、声像、八度都写在编曲器的工程里，对应到 OSM 文件夹。

已知问题
管乐和人声的合成音色距离真实乐器有差距，人声尤其明显

长曲子的合成需要几十秒到几分钟，视 CPU 核数而定

采样率固定 44.1 kHz，还没做可配置

混响用的是 Schroeder 简化版，空间感偏单薄
